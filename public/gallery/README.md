# 웨딩 사진 넣는 곳

이 폴더에 **01.jpg ~ 14.jpg** 를 넣어주세요.

- 세로 사진(3:4 또는 4:5) 기준으로 디자인되어 있습니다.
- 긴 변 **2000px 안팎**, 장당 **1MB 이하**를 권장합니다.
  (Next.js가 화면 크기에 맞춰 자동으로 줄이고 WebP로 변환하지만, 원본이 작을수록 첫 로딩이 빠릅니다.)
- 파일명 순서가 그대로 갤러리 순서입니다. `01.jpg` 가 커버(첫 화면) 사진입니다.
  - 커버를 바꾸려면 `src/config/wedding.ts` 의 `coverIndex` 를 수정하세요. (0부터 시작)
- 확장자를 바꾸고 싶다면 `src/config/wedding.ts` 의 `gallery` 부분을 함께 고치면 됩니다.

사진이 없어도 화면은 깨지지 않습니다 — 자리표시자가 대신 표시됩니다.
레이아웃을 미리 보고 싶다면:

```bash
npm run placeholders
```

이 파일(README.md)은 배포에 영향을 주지 않습니다.
